# 大模型方向面试八股 · 第一轮速记

> 求职冲刺 · 面向面试速记。每道题先给「一句话答案」，再列「答什么」要点。
> 用法：面试前 10 分钟过一遍，抓关键词展开即可，不用背长段。

---

## 1. 过拟合 / 正则化

- **一句话**：过拟合 = 模型在训练集上表现好、在验证/测试集上差，学的是「噪声」而非「规律」。
- **怎么判断**：训练 loss 持续降、验证 loss 反而升。
- **怎么缓解**：更多数据、正则化、Dropout、早停（early stopping）、降低模型复杂度。
- **正则化**：给损失函数加惩罚项，抑制权重过大，让模型更平滑、泛化更好。

## 2. L1 vs L2 正则

- **L1** = 权重绝对值之和：产生**稀疏解**（很多权重直接为 0），能自动做特征选择。
- **L2** = 权重平方和：让权重**整体变小但不为 0**，防过拟合更常用。
- **几何直觉**：L1 约束区域是菱形（角点在坐标轴 → 稀疏），L2 是圆形（处处平滑）。
- **一句话记忆**：L1 稀疏选特征，L2 平滑防过拟合。

## 3. 注意力机制 QKV

- 每个 token 通过三个不同权重矩阵，分别算出 **Query / Key / Value**。
- 流程：`Q·Kᵀ` 算相关性 → 除以 `√d` 防梯度爆炸 → softmax 归一成权重 → 加权求和 `V`。
- **角色**：Q = 我要找什么，K = 我有什么，V = 实际内容；`Q·K` 决定「关注谁」，`V` 决定「取什么信息」。

## 4. 位置编码

- **为什么需要**：自注意力对位置不敏感（打乱 token 顺序结果不变），必须额外注入位置信息。
- **正弦/余弦**（原版 Transformer）：固定公式，无需训练，可外推到更长序列。
- **可学习位置编码**（BERT/GPT）：随训练学习；**RoPE**（旋转位置编码）是当前 LLM 主流，相对位置更自然。

## 5. 幻觉原因与缓解

- **原因**：训练数据有噪声、模型是「概率预测」不是「查库」、缺外部知识、贪心解码放大错误。
- **缓解**：
  - RAG 注入外部知识（最常用、可溯源）；
  - 降低 temperature / 约束输出格式；
  - 教模型「不知道就说不知道」，加事后校验（模型自检或规则检查）。
- **工程组合拳**：RAG + 引用来源 + 输出约束。

## 6. RAG 与微调怎么选

- **RAG** = 给模型「查资料」，不改权重：适合知识更新快、要求可溯源、数据敏感的场景。
- **微调** = 改模型权重：适合固定风格/格式/领域术语、需要稳定输出结构的场景。
- **决策口诀**：要新知识 → RAG；要新能力/新风格 → 微调；**两者常组合**（先 RAG 补知识，再微调定格式）。

## 7. LoRA 原理

- 冻结原模型权重，只在旁边加**低秩矩阵 A×B**，学习「权重增量 ΔW」。
- 训练只更新 A、B（参数量极小）；推理时把 ΔW **合并进原权重**，不增加推理延迟。
- **优点**：显存省、训练快、可插拔（一个底座出多个 LoRA 适配不同任务）。

## 8. KV Cache

- 自回归生成时，每步都要算所有历史 token 的 K/V；把已算过的 K/V **缓存复用**，避免重复计算。
- **省的是计算量**（不重算历史），不是省显存——显存随序列长度线性增长。
- **相关优化**：PagedAttention（vLLM，把 KV 分页管理）、GQA/MQA（减少 KV 头数省显存）。

## 9. Agent 架构

- Agent = LLM + 工具 + 循环：**感知 → 规划 → 行动 → 观察 → 迭代**。
- **核心三件套**：规划（Planning）、记忆（短期对话 + 长期外部存储）、工具调用（Tool use）。
- **常见范式**：ReAct（推理+行动交替）、Reflexion（自我反思）、多 Agent 协作。

## 10. Function Calling

- 让模型输出**结构化参数（JSON）**，由程序去执行真正的函数，而不是让模型「自己算」。
- **流程**：定义工具 schema → 模型判断要不要调、返回函数名+参数 → 代码执行 → 结果回填给模型继续生成。
- **价值**：把 LLM 从「聊天」变成「能办事」，是 Agent 落地的基础能力。
